# Optical Balancing — Research Project

**Problematic:** geometric/grid alignment does not guarantee perceived visual balance. Toward an exact mathematical formula for visual weight in graphic design.

**Hypothesis:** each pixel group carries weight decomposable into native factor values — saturation, hue, lightness, area, position, contrast.

## Contents

- `FINDINGS.md` — draft findings (the formula verdict, factor analysis, case studies)
- `RESEARCH-PLAN.md` — plan of how to proceed (phases, the missing experiment, publication targets)
- `studies/` — full research studies: master study + 10 vein files (perception, typography, logos, formulas, factors, sources, round-2 gaps/non-English/frontier/practitioners)
- `sources/` — curated source shelves: best primary sources + academic research landscape

## Status

Two research rounds complete (2026-10-09). ~180 verified Tier 1 papers. The project is at the empirical fork: the missing experiment (Phase 2) is designed but unrun.
